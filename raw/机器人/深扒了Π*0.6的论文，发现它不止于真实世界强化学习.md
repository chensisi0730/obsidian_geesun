## 真实世界强化学习是什么？为什么重要？

你会如何学习组装盒子？你可能首先让人教你基础知识，可能会希望老师做个示范。一个好老师不仅会向你展示如何做，还会在你亲自动手时指导你，纠正你犯的错误。 **但指导的作用有限，熟才能生巧。成为组装大师的第三步是干中学，直到它成为第二天性。**

过去一年内， **机器人领域的许多成果仅建立在第一步，也就是模仿学习上。** 仅凭这一步，让机器人有一半时间成功并不难，但要让它每次都成功则非常困难，更不用说在复杂的现实世界任务中达到人类水平了。

这是一个大问题 **，机器人需要机器鲁棒、持续的工作，才能为人所用。**

## 为什么模仿学习还不够？

我们可能会问： **为什么 VLA 只靠监督学习（也就是模仿）很难长期稳定地完成任务？** 毕竟在 LLM 和很多别的机器学习系统里，监督学习效果明明很好。

这个问题的根源其实已广为人知，但一个实用的解决方案此前一直遥不可及。

当一个用模仿学习训练的 VLA 控制机器人时，它会像任何模型一样犯一些小错误——它可能把抓手放错了位置，抓取失败，或者撞倒物体。 **这些小误差会让环境变得和训练数据不一样，模型也就更容易继续犯更大的错，形成“错误越积越多”的连锁反应，导致累积错误 (compounding errors)。**

小错误可以被纠正，但累积错误会导致失败。

这对于大语言模型体系来说并不是一个大问题，大语言模型就算出错它依旧可用。 **但对要连续与世界互动的机器人来说，这会直接导致任务失败。**

## 什么是真实世界强化学习

**真实世界强化学习（Real-World Reinforcement Learning）指的是将强化学习算法应用于动态且复杂的真实环境，而不仅仅是模拟或理想化的环境中。这种方法强调智能体与环境的互动，通过实时反馈进行学习，要求算法能够处理环境的复杂性、不可预测性和多样性。**

Sergey、Chelsea一直是真实世界强化学习的倡导者。英伟达的Yuke Zhu，Jim Fan，都在研究真实世界强化学习的道路，这可能是完整的VLA训练路径里不可或缺的一环。

早在2021年，Sergey Levine就在他的博文《An Ecological Perspective on Reinforcement Learning》中引用吉布森的生态学感知理论，提出了强化学习算法的智能行为不能独立于所处的环境理解的观点。

> “吉布森指出，感知与行动之间的关系具有很强的情境性，其有效运作依赖于具身主体（即动物）与其环境之间的互动。”

他认为，正如人类和动物的感知依赖于与环境的互动，强化学习智能体的行为和泛化能力也依赖于它们所处的环境。Sergey指出，真实环境的复杂性和动态性为智能体提供了适应和广泛泛化的机会，强调仅依赖模拟环境的学习方式无法真正展现智能。

**Sergey和Chelsea带领着PI一直探索这个方向，也将一个可以在真实世界中不断学习的VLA π\*0.6带入了大家的视野。**

## 先解释一个核心概念：RECAP

RECAP 是 Reinforcement Learning with Experience and Corrections via Advantage-Conditioned Policies， **基于优势条件化策略的经验与纠偏强化学习，是一种贯穿预训练与后训练全流程的统一强化学习范式。**

![图片](data:image/svg+xml,%3C%3Fxml version='1.0' encoding='UTF-8'%3F%3E%3Csvg width='1px' height='1px' viewBox='0 0 1 1' version='1.1' xmlns='http://www.w3.org/2000/svg' xmlns:xlink='http://www.w3.org/1999/xlink'%3E%3Ctitle%3E%3C/title%3E%3Cg stroke='none' stroke-width='1' fill='none' fill-rule='evenodd' fill-opacity='0'%3E%3Cg transform='translate(-249.000000, -126.000000)' fill='%23FFFFFF'%3E%3Crect x='249' y='126' width='1' height='1'%3E%3C/rect%3E%3C/g%3E%3C/g%3E%3C/svg%3E)

RECAP主要分为三步：

- **数据收集（Data collection）**

对于预训练来说，数据仅仅是演示数据，但是对于后训练来说，数据收集分为两种，一种是自主运行，一种是人工干预。 这是 RECAP 的第一个关键创新。研究人员让机器人先上岗工作，当它在自主执行任务时犯了错（比如抓歪了、卡住了），人类专家会立即接管机器人，通过远程操作来纠正这个错误，并展示如何从这个错误中恢复过来。

这个纠正数据至关重要，因为它专门针对机器人自己犯的错误提供了解决方案。这就像一位教练在你出错的瞬间手把手教你，直接解决了累积错误的问题。

一名专家远程操作员接管并实时纠正机器人的错误

- **价值函数训练（Value function training）**

人类辅导虽然有效，但成本高昂，且无法打磨所有细节。要达到最佳性能，快速、可靠、一致地执行任务，机器人需要自主学习，这就是强化学习 (RL) 发挥作用的地方。

熟能生巧的老话不无道理，我们也需要一种方法让策略通过练习和强化来继续学习和完善机器人行为的细枝末节。

![图片](data:image/svg+xml,%3C%3Fxml version='1.0' encoding='UTF-8'%3F%3E%3Csvg width='1px' height='1px' viewBox='0 0 1 1' version='1.1' xmlns='http://www.w3.org/2000/svg' xmlns:xlink='http://www.w3.org/1999/xlink'%3E%3Ctitle%3E%3C/title%3E%3Cg stroke='none' stroke-width='1' fill='none' fill-rule='evenodd' fill-opacity='0'%3E%3Cg transform='translate(-249.000000, -126.000000)' fill='%23FFFFFF'%3E%3Crect x='249' y='126' width='1' height='1'%3E%3C/rect%3E%3C/g%3E%3C/g%3E%3C/svg%3E)

如何让机器人在真实世界探索的时候知道自己做的不好还是好，就需要引入价值函数。

PI团队利用 **目前为止收集到的所有数据训练了一个大型、多任务的价值函数** ，该价值函数能够识别失败，并判断完成任务所需的预期时间。我们后面还会提到。 **并且在不断地接受人工干预和机器人自主探索中，这个价值函数还会变得越来越强。**

- **基于优势条件化的策略训练（Advantage-conditioned training） 这是最巧妙的一步。** 在 Recap 中，价值函数先为每个状态打分，表示当前离成功有多近或多远；动作前后分数的差值就是“优势分数"，它反映了某个动作是否让机器人更接近成功还是更偏离目标。

**这个优势分数（通常简化为积极或消极）还会作为一项额外输入喂给模型。**

这就好像在告诉模型：“这个抓取动作是‘积极’的，你要学习它。” 或者 “这个插入动作是‘消极’的，你要避免它。”

通过这种方式，模型会导向那些被证明能成功的行为， **其表现自然超越了它所学习过的所有（包含好坏的）原始数据。**

## 从π0.6到π\*0.6：将RECAP思想融入预训练

Recap 的第一阶段是使用离线强化学习预训练Π\*0.6模型，这不同于π0.6 和 π0.5 VLA使用的标准监督学习方法。

**Π\*0.6相比于Π0.6，多出了一个value function model。** 这一 value function 在设计上几乎沿用了与 π0.6 相同的 VLA 架构（SigLIP+Gemma），但其语言模型 backbone 更小（约 670M 参数），计算更轻量，从而可以在训练和推理时高效运行。

**它和Π0.6共享了同一套大规模的多任务离线数据** ，包括预训练阶段积累的来自不同机器人平台、不同任务的示范轨迹（tens of thousands of hours）。

在预训练阶段，RECAP的2、3步重现， **价值函数判断出的优势信息依旧反哺给模型，让Π\*0.6成为了一个在预训练阶段就充分得到强化学习的模型** 。

## 让π\*0.6在真实世界里面变强

Π\*0.6在真实世界里面的会不断走RECAP的流程。

在完成预训练之后，机器人会被直接部署到真实场景中执行任务，例如折衣、装箱、制作咖啡。执行过程中，它会按照当前策略自主运行，一旦出现错误（如抓偏、卡住、顺序出错），人类操作员会及时接管，示范如何从错误中恢复。

**这些新数据会不断加入任务数据池，随后 Recap 会对全部数据重新训练价值函数，价值函数越训练越强，对“成功距离”的判断也越准确。** 更新后的价值函数再计算所有动作的 advantage（优势），并作为额外输入反哺给策略模型，使 π\*0.6 能够从好动作中学习、从坏动作中避开，策略自然越来越强。

三个大类的实验

- 叠衣服 - 对应Dyna Robotics
- 做咖啡 - 对应Sunday Robotics
- 折盒子 - 对应Genralist AI

这三类任务各有特点：

**组装盒子任务需要执行复杂的物理操作** ，比如在固定盒子的同时折叠盖板，还需要处理一些coner case。例如，有时扁平的盒子会粘在一起，导致机器人拿起多个盒子；有时盒子出错后，需要重新折叠。

**折叠衣物任务则需要处理大量的不确定性，包括不同的初始条件和衣物类型。** 不同的衣物需要不同的折叠策略，而且不同面料的动态特性也各不相同。

**制作浓缩咖啡是一个较难的长程任务。** 除了倒液体外，任务还需要合理安排时间，比如等待咖啡研磨机和浓缩咖啡机的工作进度，并在制作完成后用毛巾清洁设备。

## 未来方向？

今天，机器人基础模型主要使用由人类（例如，通过远程操作）手动收集的演示数据。这使得训练变得简单明了，但也带来了一个严重的障碍： **数据需要人力投入，模型的速度和稳健性被限制在人类水平的表现，而且机器人不会从经验中变得更好。**

而像Recap 这样的方法原则上可以通过额外直接从机器人自身的经验中学习来解决这些局限性。

**随着机器人在现实世界中的部署越来越广泛，从经验中学习可能成为训练数据的重要来源，以及实现高性能配方中不可或缺的一部分。**

就像人类通过演示、辅导和实践相结合的方式学习一样，机器人也将从许多不同的数据源中学习。

![图片](data:image/svg+xml,%3C%3Fxml version='1.0' encoding='UTF-8'%3F%3E%3Csvg width='1px' height='1px' viewBox='0 0 1 1' version='1.1' xmlns='http://www.w3.org/2000/svg' xmlns:xlink='http://www.w3.org/1999/xlink'%3E%3Ctitle%3E%3C/title%3E%3Cg stroke='none' stroke-width='1' fill='none' fill-rule='evenodd' fill-opacity='0'%3E%3Cg transform='translate(-249.000000, -126.000000)' fill='%23FFFFFF'%3E%3Crect x='249' y='126' width='1' height='1'%3E%3C/rect%3E%3C/g%3E%3C/g%3E%3C/svg%3E)

这些数据源将服务于不同的目的：专家提供的演示将用于定义新行为，指导将用于完善策略，而自主经验，可能是最大的数据来源，将用于完善行为，也许最终使它们能够达到超人的表现。

目前 RECAP 执行的是离线更新（它收集一批数据，重新训练模型，然后重复），而不是运行一个完全在线的 RL 循环（策略和价值函数随着数据收集实时更新），这只是因为离线更新更便于实施。 **未来，将这个方法扩展到一个完全并发的在线 RL 是一个可以期待的方向。**

## 这篇文章的亮点不止于真实世界强化学习

除了真实强化学习之外，这篇工作有以下几个亮点值得大家关注

- **一个更强的π0.6** ：虽然PI直接推出的是π0.6，但是从模型卡片中，我们看到π0.6在VL的骨干、action expert的能力上都大幅度提升，还加入了对动作风格的变量。PI在研究后训练技术的时候，始终没有放弃提升基础模型和预训练的能力。
- **Value function** 的设计有利于抓住任务失败的根因 ：在真实机器人任务中，一个最棘手的问题是 credit assignment（信任分配）：当机器人最终失败时，到底是哪一步动作造成的？例如制作浓缩咖啡时，手柄最后一步插入失败，但真正的错误可能发生在五分钟前的抓取角度。传统 RL 很难在长时间序列中准确定位“罪魁祸首”。

<video src="https://mpvideo.qpic.cn/0b2em4bumaadheako3aybbuvgz6diztqgrqa.f10002.mp4?dis_k=ee3b5f60c91146b0fbeb13252e5d890a&amp;dis_t=1777712516&amp;play_scene=10120&amp;auth_info=CoWHt+JXeUkU0dT9m14NEW0/GDpgT24eX3kmFwYVaiczCCxJCl4kJnY0QRU0fxorZw==&amp;auth_key=37e34ff7c07364ab7c3d9aea0e361ec2&amp;vid=wxv_4258771711426150411&amp;format_id=10002&amp;support_redirect=0&amp;mmversion=false" controls="">您的浏览器不支持 video 标签</video>

用模仿学习训练的基础模型难以将冲煮手柄插入浓缩咖啡机。导致失败的错误可能在更早的时候就发生了，比如以错误的角度抓取了手柄。

Recap 中的 value function 用一种非常简单但有效的方式绕过了这个难题。它并不试图判断“动作本身是不是错的”，而是学习预测：从当前这一帧出发，任务最终完成的可能性有多大（或距离成功还剩多少步）。 为了做到这一点，PI 团队使用了一个非常简单的奖励结构：

- 成功结局 = 0（最好）
- 每走一步 = -1（代表离成功还需要一步）
- 最终失败 = 一个更大的负值（比如 -C） 这样训练出来的 value function 会预测一个介于 -1 到 0 之间的值（数值越接近 0 越好），本质上表示“从这里继续走离成功还有多少步”。 它的标签来自于整条轨迹的最终结果：成功轨迹的 value 会随着进展逐渐上升到 0，而失败轨迹的 value 会从很早的状态开始被整体压低。也就是说，当任务最终失败时，这个失败的信号会沿着轨迹反向传递，使所有早期导致失败的状态都被赋予更低的 value。
- 更适用于VLA大模型的策略改进的强化学习方法，优势条件策略

PPO不适合大型的VLA模型；

AWR 会对“坏数据”给很低的权重，相当于把大量失败片段、错误片段过滤掉。但 RECAP 的核心恰恰是： **从失败里学习，特别是机器人自己在真实世界犯的错。**

优势条件策略是把 advantage 当成一个简单的“条件提示”喂给模型（例如“Advantage: positive/negative”），让 VLA 自己区分哪些动作值得学习、哪些动作应该避免。
