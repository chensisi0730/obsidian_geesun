## 具身智能—PICO遥操作项目使用说明

🤖

关于 PICO XR 机器人遥操和具身智能数据采集软件工具和示例的更新和支持，请查看开源的 GitHub [https://github.com/XR-Robotics](https://github.com/XR-Robotics) ，持续更新维护中，包括 python 支持，更多平台支持，示例工具等。

本文主要介绍基础概念和数据说明，帮助大家理解PICO在遥操作场景的主要功能。使用PICO企业版设备，您可以基于我们的开源项目实现遥操作，也可以根据底层接口自行获取各类数据。

概述

红色框软件：PICO提供，为实现遥操作和机器人训练提供数据支撑（提供获取XR HMD的各种数据和双向通信的API），让机器人公司专注在机器人软件上。

黑色框软件：机器人公司开发维护，遥操作机器人或训练机器人AI数据。
