# 资料摘要：常见仿真软件比较

> 知乎专栏基础科普文，介绍机器人仿真软件的模块组成、常见物理引擎（Bullet/ODE/MuJoCo/PhysX/Vortex/Havok）以及常用仿真平台对比，重点推荐 CoppeliaSim。

## 核心要点

- **仿真软件核心模块**：物理引擎 + 图形渲染引擎 + 脚本与插件系统 + 用户界面
- **常见物理引擎**：Bullet（开源）、ODE（开源）、MuJoCo（DeepMind 开源）、PhysX（NVIDIA）、Vortex、Havok
- **推荐平台**：CoppeliaSim（原 V-REP），其 API 系统最为灵活和完善
- ROS 本身不是仿真软件，但结合 Gazebo 可视为仿真方案

## 详细笔记

### 物理引擎对比

| 引擎 | 开源 | 维护方 | 特点 |
|------|------|--------|------|
| Bullet | 是 | 社区 | 广泛使用，PyBullet 基于此 |
| ODE | 是 | 社区 | 经典开源引擎 |
| MuJoCo | 是 | DeepMind | 多关节动力学专长 |
| PhysX | 否 | NVIDIA | GPU 加速 |
| Vortex | 否 | CM Labs | 工业级精度 |
| Havok | 否 | Microsoft | 游戏/影视 |
