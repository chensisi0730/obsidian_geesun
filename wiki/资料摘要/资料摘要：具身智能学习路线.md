# 资料摘要：具身智能学习路线

> 知乎与微信公众号文章合集，梳理具身智能和机器人控制的学习路线，涵盖强化学习和模仿学习两大范式。

## 核心要点

- **两大范式**：强化学习（RL）+ 模仿学习（IL）
- **四阶段路线**：基础 → 模仿学习 → 具身控制 → Sim2Real
- **核心算法**：PPO、SAC、TD3（RL）；BC、DAgger、GAIL（IL）
- **仿真平台**：MuJoCo、PyBullet、Isaac Sim/Lab

## 详细笔记

### 阶段一：夯实基础（1-2 个月）

#### 深度学习框架
- PyTorch（推荐）或 TensorFlow

#### 强化学习基础
- MDP：状态、动作、转移概率、奖励、折扣因子
- 价值函数：V(s)、Q(s,a)
- 经典算法：Q-Learning、DQN、PPO、SAC、TD3

#### 推荐资源

| 资源 | 特点 |
|------|------|
| 《动手学强化学习》 | 上海交大，代码开源 |
| 《Easy RL》 | 中文讲解，环境明确 |
| 《深度强化学习》王树森 | 基础详细 |

### 阶段二：模仿学习核心（1-2 个月）

#### 行为克隆（BC）
- 原理：监督学习（状态 → 动作）
- 挑战：分布漂移
- 解决：数据增强、DAgger

#### 逆强化学习（IRL）
- 原理：推断奖励函数
- 算法：MaxEnt IRL、GAIL

### 阶段三：具身智能控制进阶

#### 机器人学基础
- 刚体运动学：位姿表示、正/逆运动学
- 刚体动力学：牛顿-欧拉、拉格朗日方程

#### 物理仿真器

| 平台 | 特点 |
|------|------|
| MuJoCo | 速度快、精度高 |
| PyBullet | 开源免费 |
| Isaac Sim/Lab | GPU 加速，功能强大 |

#### 状态表示
- 视觉：CNN 处理 RGB/RGB-D
- 点云：PointNet、PointNet++
- 多模态融合

### 阶段四：Sim2Real 迁移

- 领域随机化
- 系统辨识
- 域适应
- 中间表示学习

## 学习资源汇总

### 模仿学习
