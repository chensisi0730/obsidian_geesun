# 资料摘要：7大仿真平台对比

> 深蓝AI编译的仿真平台科普文，逐一介绍 Gymnasium、MuJoCo、PyBullet、AirSim、Isaac、Genesis、AI2-THOR 七大平台的特点和适用场景。

## 核心要点

- **Gymnasium**：OpenAI Gym 维护分支，RL 标准化 API，适合入门和算法原型验证
- **MuJoCo**：DeepMind 维护，多关节动力学专长，生物力学 + 机器人学，泛用性最强
- **PyBullet**：基于 Bullet 引擎，支持 VR、ROS 集成，软体模拟，社区活跃
- **AirSim**：微软开发，虚幻引擎驱动，无人机+自动驾驶，传感器仿真精确
- **Isaac 系列**：NVIDIA 平台，GPU 加速大规模并行仿真，工业级完整工具链
- **Genesis**：纯 Python 实现，10-80x 加速，可微分+生成式 AI 集成，新一代标杆
- **AI2-THOR**：室内场景交互，照片级渲染，所有物体可操作，适合视觉导航和操作研究

## 详细笔记

### 各平台定位速览

| 平台 | 维护方 | 核心优势 | 适合场景 |
|------|--------|---------|---------|
| Gymnasium | Farama 基金会 | RL 标准 API，wrapper 系统 | 算法原型验证、基准测试 |
| MuJoCo | DeepMind | 多关节动力学，凸优化接触 | 机器人学、生物力学 |
| PyBullet | 社区 | 通用物理，VR，ROS 集成 | 操作研究、教育 |
| AirSim | 微软 | 虚幻引擎，传感器仿真 | 无人机、自动驾驶 |
| Isaac | NVIDIA | GPU 并行，端到端工具链 | 工业机器人、仓储 |
| Genesis | 开源社区 | 可微分+生成式，10-80x | 全自动数据生成、Sim2Real |
| AI2-THOR | Allen AI | 室内交互，物体状态变化 | 视觉导航、任务规划 |

### Genesis 在本篇中的定位

文章将 Genesis 定位为「革新性平台」—— 其最引人注目的特性是比现有 GPU 加速仿真器快 10-80 倍，同时整合生成式 AI，用自然语言即可生成场景和任务。

### 选择建议

- RL 入门 → Gymnasium
- 机器人动力学仿真 → MuJoCo
- 通用物理仿真 → PyBullet
- 无人机/自动驾驶 → AirSim
- 工业级方案 → Isaac
- 最前沿/数据生成 → Genesis
- 室内场景交互 → AI2-THOR
