# 资料摘要：PICO XR 遥操作项目

> PICO 企业版 XR 遥操作项目使用说明，由 XR-Robotics 开源社区维护。提供基于 VR 头显的机器人遥操作和数据采集 API。

## 核心要点

- **项目定位**：PICO 企业版设备用于机器人遥操作和具身智能数据采集
- **开源地址**：https://github.com/XR-Robotics（持续更新）
- **分层架构**：PICO 提供底层 XR HMD 数据和双向通信 API，机器人公司负责上层遥操作和 AI 训练软件
- **技术框架**：完整文档见 https://xr-robotics.github.io/

## 详细笔记

### 技术架构

```
┌──────────────────────────────────────┐
│  机器人公司（开发维护）                │
│  ┌──────────────┐ ┌───────────────┐  │
│  │ 遥操作控制    │ │ AI 训练数据    │  │
│  │ 软件          │ │ 采集软件       │  │
│  └──────┬───────┘ └──────┬────────┘  │
└─────────┼────────────────┼──────────-┘
          │ XR API         │ 数据流
┌─────────┼────────────────┼──────────-┐
│  PICO 企业版设备          │           │
│  ┌──────┴───────┐ ┌──────┴────────┐  │
│  │ XR HMD 数据  │ │ 双向通信      │  │
│  │ 获取 API     │ │ API           │  │
│  └──────────────┘ └───────────────┘  │
│  头部追踪 / 手柄 / 眼动 / 触觉反馈   │
└──────────────────────────────────────┘
```

### 输入设备能力

PICO 企业版设备可提供：
- 头部位置和方向追踪
- 手柄位置和方向追踪
- 眼动追踪（视设备型号）
- 触觉反馈
- 双向通信（控制指令下发 + 状态回传）

### 使用场景

- 沉浸式遥操作：操作员以第一人称视角控制机器人
- 数据采集：记录操作员的动作和对应机器人状态，生成训练数据集
- 示教学习：通过 VR 环境中的演示收集高质量示范数据
