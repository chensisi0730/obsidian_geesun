# Genesis

> 一个用于通用机器人学习的生成式和可微分的物理引擎，比现有 GPU 加速仿真器快 10-80 倍，原生支持可微分模拟和生成式 AI 集成。

## 是什么

Genesis 是一个从零开始构建的统一物理仿真平台，包含：
- **底层**：通用物理引擎（刚体/软体/流体/气体）
- **上层**：生成式智能体框架（场景/任务/奖励/策略自动生成）

## 为什么重要

Genesis 代表了机器人仿真基础设施的**范式转变**：

1. **性能革命**：10-80x 比 NVIDIA GPU 加速仿真器，纯 Python 实现
2. **可微分性**：原生支持 trajectory optimization 替代低效的 RL 搜索
3. **生成式 AI**：NL→场景/任务/奖励函数，全自动数据生成管线
4. **统一材料**：单一引擎支持刚体到流体所有材料类型
5. **开源生态**：跨 19 个单位的华人学者协作，纯 Python 降低使用门槛

## 工作原理

### 两层架构

```
┌──────────────────────────────────┐
│  上层：生成式智能体框架           │
│  ┌──────┐ ┌──────┐ ┌──────────┐ │
│  │场景  │ │任务  │ │奖励函数  │ │
│  │生成  │ │生成  │ │生成      │ │
│  └──────┘ └──────┘ └──────────┘ │
│  ┌──────┐ ┌──────┐ ┌──────────┐ │
│  │策略  │ │人体  │ │机器人    │ │
│  │学习  │ │动作  │ │形态生成  │ │
│  └──────┘ └──────┘ └──────────┘ │
│       统一调度 Agent             │
├──────────────────────────────────┤
│  底层：通用物理引擎              │
│  刚体 │ 软体 │ 流体 │ 气体       │
│  可微分求解器 │ 触觉传感器仿真   │
│  Python 原生 API                 │
└──────────────────────────────────┘
```

上层 Agent 接收自然语言请求，自动判断需要生成哪些内容，调度对应模块执行。

### 可微分性优势

传统仿真器只能做 forward simulation → 只能搜索/RL（低效）。Genesis 每一步都有解析梯度 → 梯度下降优化（高效数个数量级）。

## 历史与演进

- **2021**：PlastineLab（与胡渊明 Taichi 合作）——可微分模拟在机器人学习中的早期探索
- **2022-2023**：Roboninja、FluidLab、SoftZoo、ThinSellLab 系列工作（淦创团队）
- **2023**：RoboGen——利用 Genesis 作为底层引擎的全自动数据生成流水线
- **2024.12**：Genesis 正式公开发布
- **2025**：社区采用和生态扩展

## Genesis World 1.0（2026 年更新）

Genesis AI 在 2026 年正式发布 **Genesis World 1.0**，将评估而非数据生成为仿真首要目标，整栈大幅升级。

### 三大核心组件

| 组件 | 功能 | 核心特性 |
|------|------|----------|
| **Nyx** | 实时光线追踪渲染器 | 4ms 1080p 无噪声帧，path-traced 精度，零烘焙 |
| **Quadrants** | Python-to-GPU 编译器 | 跨平台高性能基础设施优化 |
| **Genesis World** | 统一物理平台 | 刚体/软体/流体/颗粒，三种互换耦合器 |

### 评估优先策略

- 仿真首先是**评估和迭代引擎**，其次才是数据生成器
- 零样本 Real-to-Sim：策略仅用真实数据训练，在仿真中评估
- 实时并排 rig（仿真器∥物理机器人），逐层定位 Sim2Real 差距来源
- Sim2Real Pearson 相关性达到 **89.96%**（95% CI: [0.7439, 0.9314]）
- MMRV 仅 **0.0166**，完美保留模型性能排名

### 渲染引擎 Nyx

- 目标：4ms 1080p 无噪声帧，path-traced 精度基线
- HDRI 环境光 + 内部扫描资产 + 3D Gaussian Splats
- 批量物理驱动，数千并行 rollout 统一管线

### 物理引擎新特性

- 支持 MJCF/URDF/USD 刚体、FEM 弹性体/布料、MPM 颗粒、SPH 流体、PBD 布料
- 三种互换耦合器：通用快速 / Drake 半解析 / IPC 无穿透
- **外部关节约束**：将关节空间动力学嵌入 IPC 优化，接触力和关节力同时求解

## 与其他仿真平台的对比

| 平台 | 速度 | 可微分 | 生成式 AI | 材料类型 | 语言 |
|------|:----:|:------:|:---------:|:--------:|:----:|
| **Genesis** | 10-80x | 原生 | 内置 | 全部 | Python |
| Isaac | 1x (基线) | 否 | 无 | 刚体为主 | C++/Python |
| MuJoCo | 适中 | 有限 | 无 | 刚体 | C |
| PyBullet | 慢 | 否 | 无 | 刚体+软体 | Python |

## 常见误解

1. **"Genesis 只是一个更快版本的 Isaac"**：错，其可微分性和生成式 AI 是根本性差异，不是量的提升
2. **"可微分性只是锦上添花"**：可微分将学习效率提升数个数量级，是另一条技术路线
3. **"纯 Python 实现会慢"**：性能反而快 10-80 倍，说明底层计算核心经过深度优化
