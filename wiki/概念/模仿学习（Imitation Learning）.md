# 模仿学习（Imitation Learning）

> 从专家示范数据中直接学习控制策略、无需显式奖励函数的学习范式，又称行为克隆（Behavior Cloning / BC），是机器人技能习得的主流路径。

## 是什么

模仿学习（Imitation Learning / IL）把人类示范视为「状态 → 动作」监督样本对，直接训练策略 π(a|s) 复现专家行为，绕开强化学习中奖励函数设计与试错采样的两大难点。本库中涉及的主要形态：

- **行为克隆（BC）**：最基础的范式——将示教数据作为监督数据集回归「观测 → 动作」映射，[[LeRobot]] 框架中 ACT / Diffusion Policy 训练均属此类
- **动作分块 BC**：以 [[ACT（动作分块变换器）]] 为代表，一次预测 k 步动作序列 + 时序集成，缓解单步预测的误差累积
- **逆强化学习（IRL）**：先从示范反推隐式奖励，再跑 RL；介于纯模仿与纯 RL 之间
- **对抗/生成式方法**：GAIL（Generative Adversarial Imitation Learning）用判别器区分专家与策略轨迹
- **人类视频预训练**：如 EgoVLA——用海量人类第一视角视频（见 [[Egocentric（第一人称视角数据）]]）预训练 VLA，再少量机器人示教微调

## 为什么重要

- **采集成本最低**：[[遥操作（Teleoperation）]] 示范数据的获取远便宜于奖励工程 + RL 大规模采样
- **安全可落地**：真机无法承受百万次试错，示范学习天然离线、无破坏风险
- **具身智能当前主力**：LeRobot 生态（SO-ARM10x / ALOHA）、π0/SmolVLA 的动作专家均以 BC + 扩散/流匹配生成器为基座
- **已知局限驱动范式演进**：累积错误与分布偏移是 IL 的核心痛点——直接催生了 [[RECAP（优势条件化强化学习）]]（真机 RL 纠偏）、π0.7 的环境预测模型蒸馏等「模仿 → 增强」路线

## 工作原理

按数据利用方式分类：

| 方法族 | 代表 | 核心思想 | 主要局限 |
|--------|------|----------|----------|
| 直接监督（BC） | LeRobot ACT/DP、π0 动作专家 | 观测→动作回归，无奖励 | 分布偏移导致误差累积 |
| 数据聚合 | DAGGER | 策略在线执行时请专家重新标注出界状态 | 需持续人类介入 |
| 逆 RL / 对抗 | IRL、GAIL | 反推隐式奖励或判别器对齐轨迹分布 | 训练不稳定，样本效率低 |
| 动作分块 + 时序集成 | ACT（CVAE） | 多步预测平滑化 + 多模态示教建模 | 仍是纯模仿，上限=示范质量 |
| 优势条件化 RL | RECAP / π*0.6 | 价值函数打分 + 人类纠正数据，真机持续学习 | 需搭建真机闭环与纠偏流程 |

**核心难题——分布偏移（Covariate Shift）**：策略一旦偏离示范状态分布，就会遇到从未见过的状态，错误逐步累积直至任务失败。缓解手段按强度递增：DAGGER 重标注 → ACT 分块平滑 → RECAP 优势条件化 → 纯 RL 自恢复。

## 历史与演进

- **ALVINN（1989）**：Pomerleau 用监督网络学习人类高速公路驾驶，常被视为 BC 路线的早期里程碑
- **DAGGER（2011）**：Ross et al. 提出数据聚合，系统性解决 on-policy 分布偏移
- **GAIL（2016/2017）**：生成对抗框架进入模仿学习，无需显式奖励
- **ALOHA + ACT（2023）**：低成本双臂遥操作平台 + 分块 Transformer 策略，把 IL 带进桌面精细操作主流
- **Diffusion Policy / π0（2023–2024）**：扩散与流匹配生成器取代回归头，处理多模态动作分布；VLA 的「视觉语言预训练 + BC 动作专家」成为标准配方
- **π*0.6 / RECAP（真机 RL 阶段）**：在 IL 基座上叠加人类纠正与优势条件化，首次大规模真机强化学习，突破示范上限

## 常见误解

- **「IL 完全不需要奖励信号」**——逆 RL 需推断隐式奖励；RECAP 的价值函数本质是隐式奖励打分
- **「BC 就是普通回归，数据越多越好」**——分布偏移下盲目堆数据可能加剧漂移，DAGGER/分块等机制比单纯加数据更关键
- **「模仿得够多就能超越示范者」**——纯 IL 性能上限≈示范质量；要超越需 RL（RECAP）或教师蒸馏（π0.7 EPM 补充执行细节）
- **「IL 与 RL 互斥」**——现代系统多为混合范式：IL 冷启动 → RL/纠正数据增强（见 CATL 规划的 Phase 4-6 RL+VLA 融合路线）

## 与相邻概念的区别

| | 模仿学习 | [[PPO（近端策略优化）]] 类 RL | [[RLHF（基于人类反馈的强化学习）]] |
|---|---|---|---|
| 信号来源 | 示范轨迹 | 标量奖励 + 试错 | 偏好对比数据 |
| 性能上限 | ≈ 示范质量 | 可超示范，但样本效率低 | 对齐人类偏好的「最优」 |
| 典型载体 | LeRobot、ACT/DP、π0 动作专家 | Unitree RL Lab、RECAP | LLM 对齐（DPO/GRPO） |

- **VLA**：[[VLA（视觉-语言-动作模型）]] 是架构，IL 是其训练范式——两者正交而非互替
- **世界模型/EPM**：π0.7 用环境预测模型作为「教师」生成带执行细节的伪示范，本质仍是蒸馏式 IL
